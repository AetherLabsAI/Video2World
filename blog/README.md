# Video2World research blog — CD-LAM template edition

Open `index.html` to view the English research announcement page. The layout, original CSS class names, article grid, TOC, typography rules, colors, sections, table styling and footer structure are preserved from the user-provided CD-LAM blog reference.

## Contents

- `index.html` — self-contained article markup and layout styles.
- `img/` — illustrations, paper excerpts, and data-faithful SVG charts; all packaged locally.
- `assets/tex-svg.js` — MathJax 3.2.2 (TeX input, SVG output), bundled locally so all mathematics renders offline. Every mathematical symbol in the article is written in LaTeX (`\( … \)` inline, `\[ … \]` display).
- `assets/fonts.css` — optional online Space Grotesk / JetBrains Mono web-font request. No font binaries are included; local system fonts are used if offline.

## Scientific provenance

- Paper: https://arxiv.org/abs/2610.04432 (v3, Oct. 9 2026)
- Project: https://aetherlabsai.github.io/Video2World/
- Source tables: Paper Table 2 (primary results; 222 reconstruction instances and 39 task families) and Table A8 with Appendix 8.2 (source-group inventory and family assignments). Success and build rates are family-macro averages.
- `figure2_agent_protocol.png` and `figure3_qualitative.png` were rendered/cropped from an author-uploaded earlier Video2World manuscript, preserving the paper's original diagrams/case examples.
- `hero_video2world.mp4` (poster `hero_video2world_poster.jpg`) is the page header: real source videos (top) paired with their simulator worlds (bottom) for DROID, FurnitureBench, HOT3D, DexYCB, RoboDojo and Poway samples, taken from the benchmark review media (reference executions, not agent submissions) and time-normalized per pair. `hero_worlds.jpg`, the previous illustrative header adapted from the earlier draft's Figure 1, is kept but no longer used.
- `build_vs_success.svg` and `geometry_vs_function.svg` visualize numbers from the current arXiv v3 Table 2 and were created specifically for this blog.
- `video2world_trailer.mp4` is the 90-second project trailer (`video/Video2World_trailer_90s_v19.mp4`, 1080p H.264 + AAC, faststart), embedded after the paper card with controls and no autoplay; `video2world_trailer_poster.jpg` is its frame at 88.5 s. Serve the folder from a server that supports HTTP Range requests so the trailer can be seeked (Python's plain `http.server` cannot).
- `causal_world.svg` is generated by `tools/gen_causal_svg.py` from `tools/causal_world.tmpl.svg`: its math is MathJax-rendered TeX embedded as glyph paths, so it needs no fonts. It is an explanatory diagram drawn for this blog from the paper's problem formulation (P = (η, π), rollouts under F_η, robot-actuation-only inputs, no direct object-state assignment). The causal framing of the post is the blog's interpretation; the paper itself does not use causal-inference terminology.
- `counterfactual_reuse.svg` and the numbers in section 05 come from an **additional experiment run for this post (October 2026), not reported in arXiv v3**: code and per-row results are in `beyond_video/` (`scripts/run_pairs.py`, `scripts/run_openloop.py`, `results/pairs`, `results/openloop`). See that README's "Changes on 2026-10-14" for the screening rule and controls.

## Note on comparisons

The human-assisted reference uses access to source information and manual refinement, and is not a matched-information, matched-budget coding-agent baseline. Figures from the earlier uploaded manuscript are for qualitative illustration; reported values follow arXiv v3.

## Deployment

All essential page images and styles are local. The optional web-font request is the only rendering-related external dependency. To host, upload the entire directory to a static web server unchanged.
